# history-thinking-visible-demo
历史材料题思维显影交互小样：2025 湖南卷 19 题第一问局部练习，不收集学生作答。

## 历史主观题闯关速查 · 老师试玩

[直接打开网页版试玩](https://yanxin-xuexi.github.io/history-thinking-visible-demo/history-quest/)

- 九个时期关卡，592 张答题卡牌，可按关键词、题型和范围筛选。
- 30 秒设问识别、高频句辨认、Boss 组装题和表达升级。
- 支持查看整本速查手册，适合老师浏览、投屏和交流试玩。
- 学习进度仅保存在当前浏览器的 localStorage 中，不需要登录；此页面没有上传作答的接口。

作品文件：[history-quest/index.html](history-quest/index.html)。页面内嵌所需图片与脚本，可保存 HTML 后离线打开。上线副本保留原有内容和玩法，将内嵌 PNG 转为同尺寸 WebP，以缩短首次加载；源文件的本机绝对路径已改为来源文件名。
