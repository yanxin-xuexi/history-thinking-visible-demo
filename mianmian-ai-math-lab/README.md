# 绵绵和 AI 的数学实验室

从数学问题与人机互动出发制作的四个课件。打开 `index.html` 可查看目录。

## 内容

- 混合运算大冒险：游戏化练习。
- 第四个“百星”用了多少年：动画与交互展示。
- 防水手电筒：带暂停点的交互视频。
- 平行与垂直：带暂停点的交互视频。

本仓库只放对外展示所需的网页、课件配置、图片和成品视频，不包含学生原始作答、诊断记录、教师答案或制作缓存。交互记录不会自动上传；页面上的正确选择也不能证明已经独立掌握。

本目录由上层 `build-mianmian-ai-math-lab.mjs` 从本地课程文件生成。发布前应重新核对视频画面与声音、手机端交互、来源授权，以及目标地区的实际可访问性。GitHub Pages 在中国大陆及微信内的稳定性不能保证。
